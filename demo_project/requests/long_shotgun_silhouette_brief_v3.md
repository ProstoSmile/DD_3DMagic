# Long shotgun — coded silhouette reference v3

This test asset is a technical silhouette reference. Its side profile is hand-authored in the Rust `GeometrySpec` through detailed, non-box extruded contours. The stock, receiver, fore-end, trigger guard, trigger, and sights use distinct curved profiles; the barrel and circular fittings use round geometry with higher tessellation.

`side_silhouette.png` is a single-color raster generated from the validated side projection mask. The top, front, and three-quarter silhouettes come from the same GeometrySpec revision. No image-generation model or supplied appearance raster is used for this Silhouette Reference.

The figure is a fictional artistic study. Relative units are not physical dimensions, and the Blender scene remains a proxy rather than a production model. This brief describes the silhouette only; material rendering is a separate optional Graphic Reference.
