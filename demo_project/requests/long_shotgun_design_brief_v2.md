# Long shotgun — design candidate v2

Fictional early-industrial game prop. Keep the long muzzle silhouette, a straight
steel barrel, compact receiver, angular walnut stock, and restrained brass fittings.
Use broad readable pixel clusters and warm wood against cool steel. No physical
measurements, functional internals, or manufacturing details are intended.

This version records the provenance of the appearance test: the source image was
generated with ChatGPT Image for this task from the material brief in
`requests/build_shotgun.json`, then imported as a fixed appearance raster. Its
registration and clipping to the programmed side contour are deterministic; the
source art itself is not reproducible from GeometrySpec. The source and clipped
image are stored together in the technical reference bundle.

The generated image is an unapproved Graphic Reference candidate. Its outer alpha
contour is clipped to the coded GeometrySpec projection. Internal material and
detail semantics have not been independently approved. Do not use its interior
details to infer or alter geometry.

Reference roles:

- Design: this brief plus the task's art direction.
- Silhouette: versioned GeometrySpec and four coded orthographic/orthographic-like
  projection outputs. This shape was authored in code, never generated from an image.
- Graphic: the source appearance raster and deterministic clipped output, both
  preserved under the matching technical geometry revision.

The object is a test fixture, not a finished production model or texture. No UV
layout or texel density was chosen.
