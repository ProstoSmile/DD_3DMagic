# Long shotgun — design candidate v1

User-requested test asset: a stylized long shotgun reference in pixel art.
This is a fictional game prop with no functional internals or manufacturing specifications.
Emphasize the long muzzle silhouette, long steel barrel, angular walnut stock,
compact receiver and readable warm/cool material separation. Use restrained ochre/brass
accents, broad dark clusters and selected edge highlights instead of random surface noise.

All proportions are artistic relative units declared in GeometrySpec. There is no chosen
physical texel density or UV atlas because this task creates reference images, not a texture
for an approved UV layout. Images are directly rasterized on a fixed pixel grid. The source
geometry and four views are generated by DD_3DMagic from one versioned specification.

Design role: this brief and the material illustration (candidate, not artist-approved).
Silhouette role: GeometrySpec, per-view projection metadata and technical sheet.
Graphic role: deterministic optional material rendering, with no image-provider call.
Source/license: original programmatic fixture authored for this project; project MIT license.
No existing artist geometry, UV or texture is targeted or unlocked. This fixture is separate
from the pre-existing TOZ-34 files. It is not a replacement for those assets.

Required acceptance views: front, side, top and a fixed orthographic three-quarter view.
Technical bounds and component placement are mechanically checked. Artistic acceptance
remains with the user. Blender proxy creation tests the bridge and is not a finished model.
